
# 🏡 Wanderlust

A full-stack travel listing platform inspired by Airbnb. Users can explore listings, create and manage their own properties, leave reviews, and view listing locations on an interactive map.

## ✨ Features

* 🔐 User authentication and authorization
* 🏠 Create, edit, and delete property listings
* ⭐ Reviews and ratings
* 🗺️ Mapbox location integration
* 🖼️ Cloud-based image uploads
* ✅ Server-side validation with Joi
* 💬 Flash messages and error handling
* 📱 Responsive interface
* ☁️ Deployed on Render

## 🛠️ Tech Stack

**Frontend:** HTML, CSS, JavaScript, EJS, Bootstrap
**Backend:** Node.js, Express.js
**Database:** MongoDB, Mongoose, MongoDB Atlas
**Authentication:** Passport.js
**Validation:** Joi
**APIs & Services:** Mapbox, Cloudinary
**Deployment:** Render

## 🏗️ Key Concepts

* RESTful routing
* MVC architecture
* CRUD operations
* MongoDB relationships and Mongoose population
* Authentication & authorization
* Express middleware
* Session management
* Server-side validation
* Third-party API integration
* Production deployment

## 🚀 Run Locally

```bash
git clone https://github.com/IvanJoseJinse5049/Wanderlust.git
cd wanderlust
npm install
node app.js
```

Environment Variables: Create a .env file in the project root and add your own MongoDB, session, Mapbox, and Cloudinary credentials. These credentials are required to run the application locally.
